## Featured projects

### 1. [Cold Outreach System (n8n + AI)](https://github.com/komalzawar22-hash/cold-outreach-n8n)

- **Stack:** Python, TensorFlow/Keras, scikit-learn

### 3. [Lung X-Ray Classification with Grad-CAM](https://github.com/komalzawar22-hash/lung-xray-classification)
Binary X-ray classifier with heatmap explanations, built as a learning demo.
- **Approach:** VGG16 transfer learning, early stopping and checkpointing, Grad-CAM visualisation
- **Stack:** Python, TensorFlow/Keras

> The two imaging projects are educational demos, not medical tools.
